# CodingCompetitions

Personal archive of coding-competition practice from roughly 2021–2023 (Google Code Jam, Kick Start, a bit of LeetCode, plus some Rust practice).

This repo is kept for reference. It is **not actively maintained**, and there is no plan to revisit unsolved problems here.

Contents are historical solution dumps and local tooling from those contests — not a packaged project, and not set up for CI.
